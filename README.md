Experiment 9 – Custom Server Using Node.js

📌 Description

This project demonstrates how to create a custom HTTP server using Node.js and explore its built-in modules.

✨ Features

- Create an HTTP server
- Handle client requests and responses
- Display system information
- Work with file and directory paths
- Create and trigger custom events

🛠️ Technologies Used

- Node.js
- JavaScript
- Built-in modules: "http", "os", "path", and "events"

🚀 How to Run

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run the command:
   node server.js
4. Open your browser and visit "http://localhost:3000".

🎯 Objective

To understand Node.js built-in modules and learn how to create and run a custom HTTP server.

✅ Expected Output

The server displays a "Hello, World!" message in the browser and prints system information and custom event details in the terminal.
